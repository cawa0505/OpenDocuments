# 🏫 LoomCowork 功能規格書：高中教務與行政資產編織系統

本文件定義並記錄了將 LoomCowork (基於 Tauri 2.0 + Rust + LanceDB) 深度整合至高中學校教務、行政系統與課表時數編織的實務場景與技術規格。
此模組作為 LoomCowork 在高度個資敏感校園環境中的殺手級落地應用。

---

## 🌐 一、 產品定位：校園隱私與髒數據的降維打擊

高中的教務行政資料（學籍、成績、課表、教師兼代課鐘點費）涉及極度敏感的個人資料（受《個人資料保護法》保護）。
傳統雲端 RAG 或 AI SaaS 軟體在進入校園時，會面臨校方資安主任與網管的嚴格審查，導致阻力重重。

**LoomCowork 的核心優勢**：
1. **純本機執行 (In-Memory & Local SQLite/LanceDB)**：所有的個資解析、課表比對、鐘點費矩陣推演，全部在本機 Process 進行，個資與數據絕不上雲。
2. **BYOK (Bring Your Own Key)**：學校可自行填入教育部、縣市教育局專案 API Key，或本機 Ollama/TAIDE（台灣專屬大模型）API 節點，軟體服務不經手任何 Key，安全邊界拉滿。
3. **極致的 Excel 友善輸出**：導出的 CSV 自動注入 UTF-8 BOM 頭 (`\uFEFF`)，保證行政人員雙擊打開時中文絕不亂碼。

## 🏫 二、 三大核心高中行政應用場景

### 1. 教學排課與教師排代課（排課組長的神級救星）
* **痛點**：高中排課是極度複雜的圖論與多變數約束問題（跨校兼課、選修課、跑班、特定教師進修時段避開）。若遇教師中途請假，需要找數名代理人拆分課表時，極易產生時間衝突。
* **打字機編織**：
  * 使用者將「全校課表.csv」與「請代課假單.txt」丟入左欄。
  * 後端 Rust 進行約束驗證與 LLM 推理。
  * **右欄資產畫布**：動態拉出一張「自適應排代衝突矩陣表」，以紅色高亮標示出重疊或不相容時段，組長確認後一鍵覆蓋。

### 2. 課表教師時數統計與兼代課鐘點費結算（行政組長期末不再爆肝）
* **痛點**：代課、超鐘點、輔導課等時數計算公式在台灣高中極其瑣碎且因假別而異，每月需要花費數日對單並用計算機按到眼睛酸澀。
* **雙通道處理機制**：
  * **黃金通道 (Golden Crate)**：在 Rust 後端寫死標準基本薪資與超鐘點公式的強型別 `struct WageCalculator`，提供 100 分的精確算力。
  * **動態自適應通道 (Adaptive Crate)**：若丟入非標準、各校客製化的「代課簽到 Excel 導出 text」，後端以 `serde_json::Map` 柔軟承接，在前端動態生成欄位並結算。
  * 一鍵產出並下載「5月份鐘點費結算總表.csv」，30 秒內自動發送出納組。

### 3. 學生選修課成果展示與成績分析（對接 GitHub Pages 一鍵發布）
* **痛點**：學校要發表多元選修、學習歷程成果、或是註冊組給班導師的落點動態分析，傳統系統導出的 PDF 極為單調難看。
* **一鍵上線**：
  * 註冊組長把學生選修成果（Markdown 或成績 CSV 數據）丟入 LoomCowork。
  * 利用前端預置的 Jamstack Tailwind SSG 模板，在記憶體內編譯為精美的網頁與視覺化圖表檔案包（`index.html`、`assets/`）。
  * 呼叫內建的 Rust GitHub API 連接器，直連學校的 GitHub Pages Repo，一鍵全球 CDN 免費部署上線。

## 🔌 三、 資料流與本機落地通訊事件

與常規發布協議一致，當組長在執行「排課衝突檢索」或「鐘點結算」時，左欄以結構化 SSE（`StreamEvent`）即時渲染狀態：

```typescript
type SchoolAdminEvent =
  | { type: "parse_start"; filename: string }       // 開始解析假單與課表
  | { type: "calculating_wage"; processed: number }  // 計算兼代課鐘點進度
  | { type: "conflict_detected"; details: any }       // 偵測到排課時段重疊
  | { type: "admin_asset_ready"; id: string }         // 行政資產大表已在右欄編織完成
```

這套規格將「隱私防線」與「高中教務髒數據自動化」完美融合，實現了為校園量身定制的高價值生產力工具！

## 🧙 四、 Skill 智能編織嚮導 (Skill Builder Agent) 與精準 Use Cases

高中的行政組長（教學組、實研組、註冊組）手裡握著極為混亂與髒亂的資料，但他們往往不具備撰寫精確 Prompt 或 JSON Schema 的能力。如果強迫行政組長手動設計與配置 Skill 包，此功能在實務上將難以推廣。

LoomCowork 透過 Tauri + Monaco Editor 的前端優勢，在系統中內建 **「Skill 智能編織嚮導（Skill Builder Agent）」**。使用者只需以最直白、感性的「人話」或抱怨描述行政痛苦，LoomCowork 即可在背景自動將強型別的 **系統提示詞（System Prompt）**、**輸入表單 Schema** 與 **右欄渲染畫布 (Canvas) 格式** 完美編織。

### 🏫 Use Case 1：教學組長的「地獄突發排代機」
* **用戶人話輸入**：
  > 「英文科的陳老師突然要請產假兩週（5/11~5/22）。我找到了兼課的林老師可以接她週一、週二的課，代課的張老師可以接週三到週五的課。但張老師週四下午自己學校有課不能排。我要怎麼把這兩週的課表安插進去，而且不能跟全校原本的課表衝突？」
* **AI 自動編織出的 Skill DNA**：
  * **Input Schema (前端自動生成表單)**：
    1. 全校總課表 (File Upload: CSV)
    2. 請假教師與區間 (String)
    3. 支援教師條件清單 (Textarea)
  * **System Prompt 核心邏輯**：
    > 「你是一個精通約束滿足問題（CSP）的排課專家。請將輸入的『全校總課表.csv』轉化為矩陣。針對陳老師的請假空缺，依據支援教師的條件（林老師:一二; 張老師:三四五且排除週四下午），計算出最佳排代時段。如果發現任何不可避免的堂數衝突，必須在輸出中明確標記。」
  * **右欄渲染格式 (Output Layout)**：`table_canvas`（自適應衝突矩陣表格）。
* **精準驗證指標**：
  1. **衝突高亮**：當 AI 偵測到週四下午林老師與張老師皆與既有課表衝突時，右欄動態表格該列需成功以紅色高亮標示（即便格式不同，前端自適應表格依然能柔軟承接不崩潰）。
  2. **欄位精準抓取**：動態表格是否能完美呈現 AI 輸出的「日期、節次、原課表班級、新安排代課老師、衝突狀態」五大欄位。

### 💰 Use Case 2：實研/教學組長的「兼代課鐘點費期末大對帳」
* **用戶人話輸入**：
  > 「每到月底我要算全校老師的鐘點費。兼課老師一節 420 元，代課老師一節 400 元，但如果代課是代『公假』，錢要由學校公費出；如果是代『事病假』，錢要從請假老師的薪水扣。每個月幾百張代課單格式都不一樣，出納組催我交總表，我快瘋了。」
* **AI 自動編織出的 Skill DNA**：
  * **Input Schema**：
    1. 當月原始代課簽到清單 (File Upload: 支持多個混亂的 txt/csv)
    2. 全校教師基本編制表 (File Upload: CSV)
  * **System Prompt 核心邏輯**：
    > 「你是一個嚴格的高中出納核算員。請比對代課清單與基本編制表。遵循以下鋼鐵公式：(兼課節數 * 420) + (代公假節數 * 400)。若假別為『事假』或『病假』，須獨立統計為『扣原始教師款』項。嚴格輸出強型別 JSON，不得漏算任何一筆姓名。」
  * **右欄渲染格式**：`table_canvas`（帶有預算公式的結算大表）。
* **精準驗證指標**：
  1. **UTF-8 BOM 頭導出驗證**：一鍵下載結算 CSV 後，雙擊打開 Windows Excel，中文教師姓名、假別與鐘點金額 100% 正常顯示，絕不亂碼。
  2. **公式精準度**：後端 `struct WageCalculator` 或高級模型能精準拆分「公假（校方支付）」與「事事病假（個人扣除）」的統計累計值。

### 📊 Use Case 3：設備/實研組長的「多元選修成果展一鍵出版」
* **用戶人話輸入**：
  > 「我們學校這學期辦了『AI與現代社會』的多元選修跑班。期末了，校長要我把 15 個學生的專題成果摘要整理出來，發布到網路上讓家長跟教育局督學看。但我不會寫網頁，學校網管又說不能把學生個資傳到外部的 SaaS 網站，怎麼辦？」
* **AI 自動編織出的 Skill DNA**：
  * **Input Schema**：
    1. 多元選修專題成果原始檔案 (File Upload: 支持 Word / Markdown 學生生資料包)
  * **System Prompt 核心邏輯**：
    > 「你是一個高階網頁主編。請將這 15 個學生的專題成果進行結構化清洗，去除敏感個資（如身分證字號、電話），保留『班級、姓名、專題名稱、核心摘要、亮點評語』。請按照標準的線上成果發表會層級結構輸出 Markdown。」
  * **右欄渲染格式**：`monaco_markdown_canvas`（精美網頁模板預覽）。
* **精準驗證指標**：
  1. **零信任本機清洗**：所有學生的原始 Word 在本地 Tauri 沙盒內生啃並過濾個資，個資絕不上傳至任何外部雲端。
  2. **一鍵 Pages 部署**：點擊一鍵發布，利用 LoomCowork 的 GitHub 連接器於 5 秒內部署至免費、全球 CDN 託管的 `.github.io`，並自動掛載好 RAG 網頁助教。

## 💬 五、 對話式技能編織器 (Interactive Skill Builder Interface)

為了完美引導使用者，LoomCowork 的 Skill 設定頁面提供專屬的「對話式技能編織器」互動介面：

1. **抱怨引導**：AI 主動提問：*「組長您好，今天又被哪項繁瑣的行政工作折磨了？請用最直白的人話跟我抱怨，並上傳一張您平常對照的 Excel 範例。」*
2. **自動生成草稿**：在使用者抱怨結束、提供範例後，AI 在右欄 Monaco 編輯器中自動以高亮形式展示編織好的 JSON Skill 配置。
3. **一鍵焊死本機**：使用者確認無誤後，點擊 **【📥 儲存為我的專屬 Skill】**。此 Skill 立即被寫入本機 SQLite，下次點開左側選單即刻變身為專屬表單，輸入資料即可極速編織！
