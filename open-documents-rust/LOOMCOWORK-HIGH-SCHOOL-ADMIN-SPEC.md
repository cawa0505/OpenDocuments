# 🏫 LoomCowork 功能規格書：高中教務與行政資產編織系統

本文件定義並記錄了將 LoomCowork (基於 Tauri 2.0 + Rust + LanceDB) 深度整合至高中學校教務、行政系統與課表時數編織的實務場景與技術規格。
此模組作為 LoomCowork 在高度個資敏感校園環境中的殺手級落地應用。

---

## 🌐 一、 產品定位：校園隱私與髒數據的降維打擊

高中的教務行政資料（學籍、成績、課表、教師兼代課鐘點費）涉及極度敏感的個人資料（受《個人資料保護法》保護）。
傳統雲端 RAG 或 AI SaaS 軟體在進入校園時，會面臨校方資安主任與網管的嚴格審查，導致阻力重重。

**LoomCowork 的核心優勢**：
1. **純本機執行 (In-Memory & Local SQLite/LanceDB)**：所有的個資解析、課表比對、鐘點費矩陣推演，全部在本機 Process 進行，個資與數據絕不上雲。
2. **BYOK (Bring Your Own Key)**：學校可自行填入教育部、縣市教育局專案 API Key，或本機 Ollama/TAIDE（台灣專屬大模型）API 節點，軟體服務不經手任何 Key，安全邊界拉滿。
3. **極致的 Excel 友善輸出**：導出的 CSV 自動注入 UTF-8 BOM 頭 (`\uFEFF`)，保證行政人員雙擊打開時中文絕不亂碼。

## 🏫 二、 三大核心高中行政應用場景

### 1. 教學排課與教師排代課（排課組長的神級救星）
* **痛點**：高中排課是極度複雜的圖論與多變數約束問題（跨校兼課、選修課、跑班、特定教師進修時段避開）。若遇教師中途請假，需要找數名代理人拆分課表時，極易產生時間衝突。
* **打字機編織**：
  * 使用者將「全校課表.csv」與「請代課假單.txt」丟入左欄。
  * 後端 Rust 進行約束驗證與 LLM 推理。
  * **右欄資產畫布**：動態拉出一張「自適應排代衝突矩陣表」，以紅色高亮標示出重疊或不相容時段，組長確認後一鍵覆蓋。

### 2. 課表教師時數統計與兼代課鐘點費結算（行政組長期末不再爆肝）
* **痛點**：代課、超鐘點、輔導課等時數計算公式在台灣高中極其瑣碎且因假別而異，每月需要花費數日對單並用計算機按到眼睛酸澀。
* **雙通道處理機制**：
  * **黃金通道 (Golden Crate)**：在 Rust 後端寫死標準基本薪資與超鐘點公式的強型別 `struct WageCalculator`，提供 100 分的精確算力。
  * **動態自適應通道 (Adaptive Crate)**：若丟入非標準、各校客製化的「代課簽到 Excel 導出 text」，後端以 `serde_json::Map` 柔軟承接，在前端動態生成欄位並結算。
  * 一鍵產出並下載「5月份鐘點費結算總表.csv」，30 秒內自動發送出納組。

### 3. 學生選修課成果展示與成績分析（對接 GitHub Pages 一鍵發布）
* **痛點**：學校要發表多元選修、學習歷程成果、或是註冊組給班導師的落點動態分析，傳統系統導出的 PDF 極為單調難看。
* **一鍵上線**：
  * 註冊組長把學生選修成果（Markdown 或成績 CSV 數據）丟入 LoomCowork。
  * 利用前端預置的 Jamstack Tailwind SSG 模板，在記憶體內編譯為精美的網頁與視覺化圖表檔案包（`index.html`、`assets/`）。
  * 呼叫內建的 Rust GitHub API 連接器，直連學校的 GitHub Pages Repo，一鍵全球 CDN 免費部署上線。

## 🔌 三、 資料流與本機落地通訊事件

與常規發布協議一致，當組長在執行「排課衝突檢索」或「鐘點結算」時，左欄以結構化 SSE（`StreamEvent`）即時渲染狀態：

```typescript
type SchoolAdminEvent =
  | { type: "parse_start"; filename: string }       // 開始解析假單與課表
  | { type: "calculating_wage"; processed: number }  // 計算兼代課鐘點進度
  | { type: "conflict_detected"; details: any }       // 偵測到排課時段重疊
  | { type: "admin_asset_ready"; id: string }         // 行政資產大表已在右欄編織完成
```

這套規格將「隱私防線」與「高中教務髒數據自動化」完美融合，實現了為校園量身定制的高價值生產力工具！
